# Formation-AIMAKER — comparateur PDIS

Application web statique pour évaluer des scénarios de mise en conformité PDIS d'un SOC.

## Fonctionnalités

- Paramétrage des pondérations par critère.
- Notation de plusieurs scénarios sur les échelles fournies.
- Diagramme Kiviat pour comparer visuellement les scénarios.
- Tableau comparatif avec notes par critère, score pondéré et note moyenne pondérée.

## Lancement local

```bash
python3 -m http.server 8000
```

Ouvrir ensuite <http://127.0.0.1:8000/>.
